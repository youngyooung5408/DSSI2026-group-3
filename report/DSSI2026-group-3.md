## 1. 專案敘述：研究問題、動機與研究方法

### 研究問題

我們想預測 2026 年九合一選舉中 22 個縣市首長候選人的得票率與當選人，並比較三組變數，基本盤（過去選舉結果）、人口結構、網路聲量，哪一組或哪一種組合對於選舉結果有最大影響力，並且利用該模型預測本次選舉。

### 研究動機

我們想檢驗常見的刻板印象，例如「北藍南綠」「老人都支持某黨、年輕人都支持某黨」，地區的人口組成或性質差異，是否真的對應不同的投票傾向，並在實際投票中扮演重要角色？還是選民其實更受政見與網路風向影響？

另外，社群媒體使用越來越普遍，我們也想知道網路討論聲量能否反映到實際投票，雖然無法得知發文者住在哪裡、有沒有投票權，但它或許能作為一個有預測力的變數。

由於今年適逢九合一選舉，正好可以剛好驗證模型與假設，我們認為是個非常好的機會做關於選舉的研究。

### 資料來源

以下是我們的資料來源：

1. 中選會選舉資料庫：歷屆縣市長、總統、立委選舉結果；選舉公報（候選人政見）
2. 內政部：各縣市年齡、教育程度等人口統計
3. 財政部：綜合所得稅所得統計
4. 行政院主計總處：人力資源調查（失業率、勞動參與率）
5. 台灣民意基金會：每月政黨支持度民調
6. 網路聲量：PTT、臉書等論壇與社群媒體討論數量；Google 搜尋量；選舉觀測站網站的每週聲量

### 研究方法

- 預測目標為各候選人的得票率，而非當選機率：歷史資料有實際得票率可供訓練，且能同時看出候選人之間的高低與差距，得票率最高者即為預測當選人。
- 為避免樣本少造成 overfitting，參考文獻建議先用簡單模型，再逐步加入變數。我們將分三個模型比較：模型 1 只含基本盤（前次選舉結果，如上屆同黨得票率、是否現任）；模型 2 為基本盤加人口結構變數；模型 3 為基本盤加網路聲量變數。
- 以歷屆資料回測，比較各組變數加入後的解釋力與預測力是否提升（如係數顯著性、樣本外預測誤差），挑選預測力最好的組合作為 final 模型，預測 2026 年結果。
- 評估有兩項：（1）得票率預測準不準；（2）當選人有沒有預測對。另與「只依藍綠基本盤」的 baseline 比較，看模型能多準多少。
- 待與助教討論：若模型 1 用 OLS，模型 2、3 改用 random forest 等 machine learning 方法，模型與變數同時改變，就難以判斷結果差異來自變數還是模型，會不會影響我們的詮釋？
- 政見處理（選做）：把選舉公報政見拆成句子向量，以內積比較候選人政見的相似度，並與人工比對並行試做。
- 模型雛形：
- VoteShare = β0 + β1 基本盤 + β2 人口結構 + β3 網路聲量 + ε

## 4. 假說與預期主要結果

- 台灣常見「北藍南綠」「老人支持某黨、年輕人支持某黨」等說法。我們想檢驗，在控制基本盤（過去選舉結果）之後，人口結構與網路聲量是否還能提供額外的預測力：
- H1：人口結構在基本盤之外，能多解釋一部分選舉結果，即模型 2 的預測誤差小於模型 1。
- H2：網路討論聲量在基本盤之外，能提升選舉結果的預測力，即模型 3 的預測誤差小於模型 1。
- H3（交互作用，視時間再做）：平均年齡較低的地區，網路聲量對得票率的影響較大。

## 5. 預期限制：

- 樣本數太少：約 22 縣市 × 3 屆，容易 overfitting。
- 地方派系與個人魅力難以量化：派系只能勉強用前次選舉結果反映；若地方勢力推出新人、無黨籍或跨黨候選人，就無法捕捉。
- 人口結構不等於實際投票者：沒有考慮投票率，設籍人口也可能不在當地投票。
- 各縣市人口結構在兩屆之間的變化可能很小，難以解釋選舉結果的變化。
- 網路聲量無法得知發文者是否為當地選民；歷屆輿情資料可能不完整，且不做正負面情緒判斷。
