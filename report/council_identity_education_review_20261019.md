## 核對方法與特殊個案

1. 固定前輪CSV、原始人物頁及中選會archive版本，逐檔核對SHA-256。保留candidate_key，不以同名直接合併。
2. 對照縣市、姓名、編號選區與2022當選註記；中選會格式的*為當選、!為婦女保障當選，空白或-不推定日後沒有遞補。
3. 新竹縣跨屆編號差異：目視[114年9月26日中選務字第1143150729號公告](https://web.cec.gov.tw/api/file/339375cf-f16c-4e4f-ba44-ec4a9502088f.pdf)第1、2頁，並與2022地理資料核對，建立舊第1選區分為新1、2，其餘順延的明確對照。25筆直接取得跨屆連結支持；另一筆陳栢誠另以遞補紀錄補足。相同或對照編號不代表地理邊界未變。
4. 謝典霖／謝典林：採官方學校轉載的議會更名公告；不模糊匹配其他姓名。
5. 許采蓁／許釆蓁：目視[2022高雄市第8選區官方公報](https://bulletin.cec.gov.tw/01選舉公報/05直轄市議員/111年/06高雄市/高雄市第8選區.pdf)第1頁第3位，生日民國74年6月3日與學士學歷對上archive紀錄後，明列個案字形對照。
6. 11筆補選／遞補佐證：吳建德、陳栢誠、鄭聚然、吳韋達、蕭文雄、張秀枝、黃建溢、高美珠、莊光大、吳佩雯、董昌華。保存事件、來源、頁碼及證據層級；其中2筆是官方公告標題、1筆是議會網站轉載新聞，其餘為已讀完整相關決議或目視名單。事件支持歷史連結，不代表2026仍在任。

## 學歷整理

可追溯2022申報學歷分組者689位：研究所343、大學190、大學以下156。其餘3位留空，沒有補造學歷。

| 兩來源學歷比較 | 筆數（分母692） |
| --- | ---: |
| 官方原文已有，學位層級仍待判讀 | 317 |
| 兩來源申報學歷層級一致 | 295 |
| 內政部學歷空白，歷史申報另列 | 77 |
| 來源年代或層級差異，待複核 | 3 |

- MOI原文未明說已取得學位時，不自動由學校名稱推定畢業。副學士獨立於學士，分組歸入大學以下。
- 36位來源含在學、肄業、學分班、研究班、在職專班、論文口試等子句；這些子句不升格為已取得學位，同一人其他明確學位仍分項保留。
- 層級差異可能是資料年代、更新或申報口徑不同，不直接判定任何一方造假；原文與2022申報各自保存。
- 689位「2022申報分組」不是689位「2026最高學歷確認」，295位層級一致也不是獨立學位認證。
